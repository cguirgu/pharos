# New Athena Unicode

Regular font, version 5.008 (2021-08-15), distributed by the Society for Classical
Studies. Used for the shared Coptic typeface in `src/ui/theme.ts` and loaded locally
by `app/_layout.tsx` on native and web.

- Publisher: https://www.apagreekkeys.org/NAUdownload.html
- Original archive: https://www.apagreekkeys.org/fonts/NAU5_008.zip
- `NewAthenaUnicode.ttf` is the unmodified `NAU5_008/newathu5_8.ttf` from that archive.
- `NewAthenaUnicode-OFL.pdf` is the original `NAU5_008/NAU5_OpenFontLicense.pdf`.
- License: SIL Open Font License 1.1; the reserved font name is New Athena Unicode.

The font supports both the Coptic block and the Egyptian-derived letters in the
Greek and Coptic block. Text stays Unicode; no legacy ASCII substitutions are used.
